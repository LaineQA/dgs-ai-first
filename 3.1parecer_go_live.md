## 4. Parecer de Go-Live

### Veredicto: **🚫 NÃO recomendado para produção no estado atual**

### Fundamento

O sistema demonstra boa base de conhecimento: 6 de 8 respostas aprovadas, precisão factual alta (D1 consistentemente 2–3), e comportamento correto tanto para perguntas de escopo quanto para tiers inexistentes (sem alucinação). Isso indica que o pipeline RAG está funcionando e a base documental está bem indexada.

No entanto, as **2 falhas são ambas de guardrail (D3 = 1)**, não de conhecimento. Isso significa que o problema não está nos documentos ingeridos — está nas **regras comportamentais do assistente**, provavelmente no system prompt ou AGENTS.md. São falhas determinísticas e reproduzíveis:

- Qualquer pergunta sem um dado obrigatório pode gerar uma assunção indevida (padrão da Resposta 6).
- Qualquer usuário que escreva em outro idioma receberá resposta naquele idioma (padrão da Resposta 8).

Em produção, ambos os cenários ocorrem com frequência real em operações de atendimento.

### Caminho para go-live
Corretas as duas regras bloqueantes (itens 1 e 2), o sistema deve ser submetido a uma nova rodada de testes cobrindo pelo menos: pergunta sem dado obrigatório, pergunta em idioma estrangeiro, e um caso de frete com contrato antigo (para validar a disposição transitória PROC-042-v2 §5). Se as 8 respostas passarem nessa nova rodada com score médio ≥ 2,5, o sistema está pronto para go-live.
