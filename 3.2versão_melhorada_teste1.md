## Teste 1

```typescript
import { describe, it, expect } from 'vitest';
import request from 'supertest';
import { app } from '../src/app';

describe('query endpoint', () => {
  it('should return a valid resposta estruturada para prazo de devolução', async () => {
    const res = await request(app)
      .post('/api/query')
      .send({ question: 'prazo devolução' });

    expect(res.status).toBe(200);
    expect(res.body).toEqual(
      expect.objectContaining({
        answer: expect.any(String),
        source_document: expect.any(String),
        confidence_score: expect.any(Number),
      })
    );

    expect(res.body.answer.toLowerCase()).toContain('7 dias');
    expect(res.body.source_document).toBe('POL-001');
    expect(res.body.confidence_score).toBeGreaterThanOrEqual(0);
    expect(res.body.confidence_score).toBeLessThanOrEqual(1);
  });
});
```

### Melhorias:

- Verifica o conteúdo da resposta, não apenas que `res.body` existe.
- Confirma que o endpoint devolve um output estruturado (`answer`, `source_document`, `confidence_score`).
- Garante que a resposta refere-se ao prazo de devolução esperado e cita a fonte correta.
- Usa `Vitest`, que é o framework correto do projeto, em vez de `jest`.
